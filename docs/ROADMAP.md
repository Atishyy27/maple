# Maple roadmap

## Tiers

| Tier | What it is | Done when |
|---|---|---|
| T0: personal tool (now) | Fills one form from your data; you review and submit | Clean repo, CI green, answers filled, works on real forms |
| T1: batch applying | Reads a job sheet, skips jobs you fail, picks a CV, fills each form, and records each outcome | One run across real jobs, with time per application measured |
| T2: portfolio | Public repo, demo video, measured results | T1 numbers exist |
| T3: product for others | Extension, onboarding, no local setup | Other people ask for it; decide then |

## T1 scope

1. Import job rows from a sheet and remove duplicates.
2. Eligibility check before any form opens: batch, branch and published gates.
3. CV choice per role, from your existing CVs.
4. Fill and pause for review. Submit and captcha stay with you.
5. Record the result in the applications ledger.
6. Add each skipped field to the answer bank backlog after every run.

## Measures

Time per application, fields filled correctly, fields left blank, wrong values (target 0), and replies per application.

## Not now

Auto-submit, captcha solving, LinkedIn automation, and any AI that writes facts about you.
